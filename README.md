# Sistema de Reservas - Club Atlético Villa Norte

Proyecto desarrollado para la entrega final de la cursada **Generación T**.  
Sistema web integral para la gestión de reservas de canchas (fútbol 5, pádel y tenis), precios variables, control de concurrencia, lista de espera automatizada y penalizaciones[cite: 1, 2, 3, 5, 8].

## 📂 Estructura del Repositorio
- `/frontend`: Interfaz de usuario completa[cite: 1].
- `/backend`: API, lógica de negocio y conexión a base de datos[cite: 1].
